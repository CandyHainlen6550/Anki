# Third-party notices

## KanjiVG

Stroke-order data is derived from the KanjiVG project and embedded for offline use. KanjiVG data is licensed under CC BY-SA 3.0. Attribution is kept here rather than rendered on each learner card.

## HanaMin / Hanazono Font

Rare Unicode component outlines are generated at build time from HanaMinA/HanaMinB fetched from `googlefonts/chinese`. HanaMin is dual-licensed under the Hanazono Font License and SIL Open Font License 1.1. The original TTF files are build dependencies and are not shipped in the APKG.

## GlyphWiki

Named component entities without a Unicode code point are fetched from GlyphWiki during the build and embedded as SVG glyph images. HanaMin is itself produced from GlyphWiki glyph data. GlyphWiki data permits use, copy, distribution, and modification; see the GlyphWiki project/dump license for the full notice.

## Handwriting recognizer

The card-side geometry/recognition approach is adapted from `mxggle/kanji-recognizer` (MIT). Attribution is kept here rather than learner-facing cards.
